# Repository Instructions

- Preserve Hebrew text exactly in all files. Never allow Hebrew labels, names, or content to be replaced with `?` or mojibake.
- Use UTF-8 for all text file edits.
- When editing Hebrew-sensitive constants, templates, or UI labels, prefer UTF-8-safe tools and verify the saved content with a UTF-8 readback.
- Do not rename Hebrew worker names, labels, or UI copy unless explicitly requested.
